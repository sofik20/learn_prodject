# Фермерский дворик 🐄🌾

Двухсервисное веб-приложение для учёта товаров интернет-магазина фермерских продуктов.

---

## 📋 Описание

**Предметная область:** Интернет-магазин фермерских продуктов  
**Основная сущность:** Продукт (Product)

Приложение позволяет:
- Просматривать список продуктов
- Добавлять новые продукты
- Редактировать существующие
- Частично обновлять данные
- Удалять продукты

---

## 🧱 Архитектура

| Слой | Технология | Порт |
|------|------------|------|
| Backend API | FastAPI + Pydantic + SQLite | 8000 |
| Frontend | Flask + HTML/CSS (без JavaScript) | 5000 |

Frontend не работает с базой данных напрямую — все запросы идут через REST API backend.

## 🗄️ База данных

**Файл:** `farm_shop.db`  
**Таблица:** `products`

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER PK | Уникальный идентификатор |
| name | TEXT | Название продукта |
| category | TEXT | Категория |
| price | REAL | Цена за единицу |
| quantity | INTEGER | Количество в наличии |
| farm | TEXT | Название фермы |
| organic | INTEGER | Органик (0/1) |

---

## 🔌 API-маршруты (FastAPI)

| Метод | Маршрут | Действие |
|-------|---------|----------|
| GET | /products | Список всех продуктов |
| GET | /products/{id} | Один продукт |
| POST | /products | Создать продукт |
| PUT | /products/{id} | Полностью обновить |
| PATCH | /products/{id} | Частично обновить |
| DELETE | /products/{id} | Удалить продукт |

Swagger-документация: `http://127.0.0.1:8000/docs`

## 🚀 Запуск

### 1. Установить зависимости
\`\`\`bash
pip install -r requirements.txt
\`\`\`

### 2. Запустить backend
\`\`\`bash
cd backend
python -m uvicorn main:app --reload --port 8000
\`\`\`

### 3. Запустить frontend (в другом терминале)
\`\`\`bash
cd frontend
python app.py
\`\`\`

### 4. Открыть в браузере
- Frontend: `http://127.0.0.1:5000`
- Swagger: `http://127.0.0.1:8000/docs`

## ✅ Тестирование API

Тестирование проводилось через Swagger (`/docs`):
- POST — создание продукта (код 201)
- GET — получение списка (код 200)
- GET /{id} — получение по ID (код 200 / 404)
- PUT — полное обновление (код 200)
- PATCH — частичное обновление (код 200)
- DELETE — удаление (код 200)
